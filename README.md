# 📝 Python To-Do List (v1)

A simple command-line To-Do List application built with Python. This project allows users to manage daily tasks directly from the terminal.

## ✨ Features

* ➕ Add new tasks
* 📋 View all tasks
* ❌ Remove completed tasks
* 🚪 Exit the application safely
* 🖥️ Easy-to-use menu-driven interface

## 📂 Project Structure

```
todo-list/
│── todo.py
└── README.md
```

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:

```bash
git clone https://github.com/<your-username>/<repository-name>.git
```

3. Navigate to the project folder:

```bash
cd <repository-name>
```

4. Run the program:

```bash
python todo.py
```
